Questions

The things people ask before they install it.

Where do I download Vitals?

Press for the Windows installer, the Linux and Raspberry Pi files, and the Android app. Every file comes from the project's GitHub Releases page.

Install the agent on each computer you want to watch, then pair it with the phone app by scanning the QR code it shows.

Is it free?

Yes. Vitals is free and open source under the MIT licence. There are no ads and no paid tier.

Which computers does it work on?
  • Windows 10 and 11, 64-bit
  • Linux with systemd: Ubuntu, Debian, Fedora, Arch and others, on x86-64 or ARM64
  • Raspberry Pi 3, 4 and 5 running a 64-bit OS such as Raspberry Pi OS (64-bit)

macOS isn't supported yet.

What Android version do I need?

Android 8.0 (Oreo) or newer. There's no iPhone app yet.

How much RAM and CPU does it use?

Very little. Measured on real machines while nobody is watching:

  • Windows laptop: 14.2 MB RAM, 0.08% of one CPU core
  • Linux server: 11.8 MB RAM, 0.04%
  • Raspberry Pi 4: 9.4 MB RAM, 0.12%

While you have a device open in the app it sends live readings every second and stays under 25 MB and 1% of a core. The optional Windows tray icon adds about 15 MB.

Do I need to open ports or have a static IP?

No. Every connection goes out from your computer, so it works behind home routers, CGNAT and mobile data with nothing to forward.

Why does Windows warn me when I run the installer?

The installer isn't code-signed yet, so SmartScreen shows a notice. Choose More info, then Run anyway.

To check the file is genuine, compare its SHA-256 hash with the SHA256SUMS file on the release page.

Why does it ask to install a driver on Windows?

Windows only lets programs read CPU temperatures through a driver. Vitals offers the signed PawnIO driver for that. It's optional: without it you still get load, clock speeds, RAM, GPU, battery and drives, just not CPU temperatures.

What data does Vitals keep?

Your email, a hash of your password, details of the computers you pair, and their recent readings. By default it also sends the names of the top 5 programs by memory use, which you can turn off.

Minute-by-minute history is deleted after 7 days. Nothing is sold. You can export your data or delete your account at any time. The privacy policy has the details.

Can I contribute?

Yes. Report bugs or suggest features in GitHub Issues, and send changes as pull requests. Small fixes are welcome without asking first.

Found a security problem? Please email contact@vitals.dpdns.org instead of opening a public issue.

Vitals

Vitals is a free, open-source hardware monitor for your PCs, servers and Raspberry Pis. It shows temperatures, load and health on your phone and alerts you when something runs hot.
