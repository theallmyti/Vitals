It was subset to the characters the website uses and converted to WOFF2 to make
the page smaller. Under the OFL a subset is a Modified Version, and
"Press Start 2P" is a Reserved Font Name, so the subset is renamed "Vitals Pixel".
No glyphs were redrawn. The same font is embedded in index.html.
